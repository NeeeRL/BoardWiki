# 仕様書

最終更新: 2026-10-29

情報工学基礎実習の課題です。実際の仕様などを定義します。

## 1 システム概要

### 1.1 アプリの説明
ボードゲーム(以下ゲーム)の歴史やルールをまとめた情報サイトです。MITライセンスで公開されているゲームを使ってゲームを実際にプレイすることができます。

### 1.2 アプリの機能
ゲームの歴史、ルールの閲覧・ゲームのプレイができる

### 1.3 システム構成
- フロントエンド: Next.js App Router
- UI/アニメーション: Tailwind CSS
- 開発言語: TypeScript
- パッケージ管理: npm
- 実行環境: Docker / Docker Compose
- Webサーバー: Nginx
- 配信方式: Static Export（静的サイト）

バックエンド・データベースなどは使用しない方針。JSONを使用する。ゲーム機能はMITライセンスのものを使用。

### 1.4 実行構成
ルートディレクトリにコードを配置する。Dockerで実行する。

## 3 画面ルーティング一覧

| パス | ページ名 | 概要 |
| --- | --- | --- |
| `/` | ホーム | おすすめ・人気ゲーム・ジャンル一覧 |
| `/games/[slug]` | ゲーム詳細 | ゲーム紹介・遊び方・プレイ画面 |
| `/play/[slug]` | ゲームプレイ | ゲームのプレイ |
| `/licenses` | ライセンス | ゲームごとのOSSライセンス情報 |
| `/_not-found` | 404ページ | 存在しないページの案内（URLとしては通常の404） |

## 4 ページ仕様

### 4.1 ホーム

以下の要素を含む

- 遊べるゲーム一覧
- thumbnail
- 使わせていただいたゲームのリンク

### 4.2 ゲーム詳細

`slug`はゲームごとに固有な値である。
以下の要素を含む

- ゲームタイトル
- 同時に遊べる人数
- 遊び方
- 誕生から今までの遷移

### 4.3 ゲームプレイ

OSSゲームをそのまま配信させていただく
しかし、ライセンスを確認できることは必須要件である

### 4.4 ライセンス

ゲームごとのライセンスをまとめたページ
それぞれのカードは以下の要素を含む

- title
- thumbnail
- github link
